# نظام إدارة معامل الأسنان — مركز الدكتور عقلان الكامل

تطبيق أندرويد لإدارة إرساليات معامل الأسنان: متابعة الإرساليات وحالاتها، حسابات
المعامل والمدفوعات متعددة العملات، المخزون والمواد، التقارير و PDF، قارئ QR،
والنسخ الاحتياطي السحابي.

- **الحزمة:** `com.aistudio.dentallab.mgmt`
- **أقل إصدار مدعوم:** أندرويد 7.0 (API 24)
- **التقنيات:** Kotlin + Jetpack Compose + Room + Firebase

---

## التشغيل السريع (تثبيت التطبيق فقط)

1. انسخ ملف `app-release.apk` إلى الهاتف.
2. فعّل «تثبيت التطبيقات من مصادر غير معروفة» لتطبيق «الملفات» أو المتصفح.
3. افتح الملف وثبّته.
4. عند أول تشغيل ستظهر شاشة **الإعداد الأول**: اكتب اسم المدير واختر رمز مرور
   خاصاً بك (٤ أرقام على الأقل).

> **مهم:** لا يوجد رمز مرور افتراضي في التطبيق ولا يمكن استرجاع الرمز إذا نسيته.
> احتفظ به في مكان آمن.

## البناء من المصدر

### المتطلبات
- JDK 17 أو أحدث (تم الاختبار على JDK 21)
- Android SDK: `platforms;android-36.1` و `build-tools;36.1.0`
- Gradle: يُنزَّل تلقائياً عبر الـ wrapper (الإصدار 9.3.1)

### الخطوات

```bash
# 1. مسار Android SDK
echo "sdk.dir=/path/to/android-sdk" > local.properties

# 2. مفتاح توقيع الإصدار (مرة واحدة فقط — احتفظ بالملف والكلمة في مكان آمن)
keytool -genkeypair -v \
  -keystore aqlan-lab-release.jks \
  -alias upload -keyalg RSA -keysize 4096 -validity 10950 \
  -dname "CN=Aqlan Dental Center, O=Dr Aqlan Alkamel Center, L=Taiz, C=YE"

# 3. بناء نسخة الإصدار الموقّعة
export KEYSTORE_PATH="$PWD/aqlan-lab-release.jks"
export STORE_PASSWORD="كلمة-المرور"
export KEY_PASSWORD="كلمة-المرور"
./gradlew :app:assembleRelease

# الناتج: app/build/outputs/apk/release/app-release.apk
```

### الفحوصات قبل أي تعديل

```bash
./gradlew :app:testDebugUnitTest     # اختبارات الوحدة والانحدار الأمني
./gradlew :app:assembleDebug         # بناء نسخة التطوير
```

> ملف مفتاح التوقيع (`*.jks`) وكلمات المرور **يجب ألا تُرفع إلى المستودع أبداً** —
> `.gitignore` يمنعها. فقدان المفتاح يعني عدم القدرة على إصدار تحديث يستبدل
> النسخة المثبّتة على الأجهزة.

## إعداد الخدمات السحابية (اختياري لكنه ضروري للنسخ الاحتياطي)

التطبيق يعمل بالكامل بدون إنترنت. الميزات السحابية (المزامنة، النسخ الاحتياطي
على Firebase Storage، تسجيل الدخول بالبريد أو Google) **معطّلة حتى تُربط بمشروع
Firebase خاص بالمركز**، ويعرض التطبيق رسالة واضحة بذلك بدل إظهار نجاح وهمي.

### 1. ملف `google-services.json`
1. أنشئ مشروعاً على <https://console.firebase.google.com>.
2. أضف تطبيق أندرويد بالحزمة `com.aistudio.dentallab.mgmt`.
3. نزّل `google-services.json` وضعه في `app/google-services.json`.
4. أعد البناء.

### 2. قواعد الأمان — خطوة إلزامية
مشروع Firebase جديد يبدأ إما بوضع اختبار مفتوح للجميع أو بوضع مغلق تماماً.
القواعد الصحيحة موجودة في مجلد `firebase/`:

```bash
firebase deploy --only firestore:rules
firebase deploy --only storage
```

**لا تُفعّل النسخ الاحتياطي السحابي قبل نشر هذه القواعد** — بيانات المرضى
والحسابات المالية سترفع إلى مسار يمكن الوصول إليه.

### 3. تسجيل الدخول عبر Google (اختياري)
انسخ «Web client ID» من:
Firebase Console ← Authentication ← Sign-in method ← Google ← Web SDK configuration
ثم ضعه في `app/src/main/res/values/strings.xml` في `google_web_client_id`.
تركه فارغاً يُبقي الزر معطّلاً برسالة واضحة.

## الأمان — ما يجب معرفته

| البند | الحالة |
|---|---|
| رموز المرور | مُجزّأة بـ PBKDF2-HMAC-SHA256 (120 ألف دورة + ملح لكل مستخدم) |
| رموز افتراضية / أبواب خلفية | لا توجد — يُعيَّن الرمز عند أول تشغيل |
| الحماية من التخمين | حظر تصاعدي بعد ٥ محاولات خاطئة |
| البصمة | تحقق حقيقي عبر `BiometricPrompt` من النظام، ويجب تفعيلها يدوياً أولاً |
| النسخ الاحتياطي التلقائي لأندرويد | معطّل (`allowBackup=false`) — قاعدة بيانات المرضى لا تخرج إلى Google Drive |
| لقطات الشاشة | ممنوعة (`FLAG_SECURE`) |
| الإشعارات | لا تعرض أسماء المرضى على شاشة القفل |
| قاعدة البيانات على الجهاز | **غير مشفّرة** — انظر التوصية أدناه |

### توصية مفتوحة: تشفير قاعدة البيانات
قاعدة بيانات Room محمية بعزل نظام أندرويد بين التطبيقات، لكنها غير مشفّرة على
القرص. على جهاز مُجذَّر (rooted) أو عبر فحص جنائي للجهاز يمكن قراءتها. لرفع
مستوى الحماية إلى مستوى بيانات المرضى، يُنصح بإضافة **SQLCipher** مع مفتاح
مُولَّد ومحفوظ في Android Keystore. لم يُطبَّق هنا لأنه يتطلب هجرة بيانات
مدروسة واختباراً على أجهزة فعلية.

## هيكل المشروع

```
app/src/main/java/com/example/
├── MainActivity.kt              # نقطة الدخول + القفل التلقائي + FLAG_SECURE
├── security/                    # تجزئة رموز المرور، البصمة، الإعدادات الدائمة
├── data/
│   ├── AppDatabase.kt           # Room + الهجرات
│   ├── DatabaseMigrations.kt    # هجرات المخطط (لا تُستخدم fallbackToDestructiveMigration)
│   ├── models/                  # الكيانات
│   ├── dao/                     # استعلامات Room
│   └── repository/              # منطق الأعمال والتدقيق
├── network/                     # Firebase Auth / Firestore / Storage
├── ui/
│   ├── navigation/              # المسارات + حارس الصلاحيات RoleGuard
│   ├── screens/                 # الشاشات
│   ├── components/              # مكونات مشتركة وهوية المركز
│   └── viewmodel/               # الحالة والمنطق
└── util/                        # PDF، الإشعارات، QR
firebase/                        # قواعد أمان Firestore و Storage
```
